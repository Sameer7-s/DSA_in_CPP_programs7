## 📌 About

This repository documents my hands-on journey learning **Data Structures and Algorithms** using **C++**. It contains topic-wise implementations, college lab programs, and problem-solving practice — from C++ fundamentals through linked lists, stacks, queues, and beyond.

> This is a learning repository. The code reflects my actual progress and understanding at each stage.

---

## 📚 Topics Covered

### 🔹 C++ Basics
- Input / Output
- Loops & Pattern Printing
- Functions (with & without arguments, default parameters)
- Recursion (Factorial)
- Number Conversions (Binary ↔ Decimal, Reverse Number)

### 🔹 Arrays
- 1D Array Operations (insert, traverse, merge, reverse, rotate)
- 2D Array Operations (row/column sum, transpose, diagonal print, max/min)
- Sum & Average, Even/Odd Count, Frequency Count

### 🔹 Searching
- Linear Search
- Binary Search

### 🔹 Sorting
- Bubble Sort
- Selection Sort
- Insertion Sort

### 🔹 Pointers
- Pointer Basics with Classes

### 🔹 Linked List
- **Singly Linked List**: Creation, Insertion (beginning, end, specific position), Deletion, Traversal, Count Elements
- **Circular Linked List**: Insertion, Deletion, Traversal
- **Doubly Linked List**: Insertion

### 🔹 Stack
- Stack using Array (Push, Pop, Peek, Overflow/Underflow)
- Stack using Linked List
- Stack using STL
- Applications: Reverse a String using Stack

### 🔹 Queue
- Queue using Array (Enqueue, Dequeue, Peek)
- Queue using Linked List

### 🔹 Strings
- String Input/Output, getline
- String Operations (append, sort, reverse, push_back, pop_back)
- String Problems (palindrome, copy, vowels/consonants, case conversion, length without built-in)

### 🔹 STL (Standard Template Library)
- Vector basics, 2D Vector, Sorting with Vectors

### 🔹 OOP (Object-Oriented Programming)
- Classes & Objects
- Constructors (Default, Parameterized)
- Destructors
- Access Specifiers (Public, Private)
- `this` Keyword
- Pointers with Objects
